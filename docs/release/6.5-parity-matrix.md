## 已知边界

- JavDB、JavBus 和第三方服务的线上页面与接口仍可能变化；发布门禁使用固定 fixture 保证可重复。
- 123/115 自动测试使用隔离 provider，不会创建真实云端任务。
- 启动性能按 Windows Edge 与 GitHub Ubuntu Chromium 分别使用固定的 30 样本基线，避免把不同浏览器和机器速度混成同一门槛。
- `output/` 是本地审计与测试输出，不纳入发布提交。
