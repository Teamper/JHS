# WebDAV 同步与恢复

从 6.5.2 切换到 7.0 后，可在「设置 → 备份与数据 → 多端自动同步」接入自动同步。设备之间使用相同的 WebDAV 库，升级前可在同页导出本地备份。

## 接入和使用

1. 在每个浏览器或设备填写地址和账号并保存。支持共用连接的同一用户脚本安装中，JavDB 和 JavBus 共用加密保存的连接。旧连接冲突时在设置中选择「使用此连接」。
2. 首次接入会创建本地恢复点。已有云端与本机记录发生冲突时以云端为准，本机独有内容保留。后续变更按字段版本合并。
3. 保存后可用「立即同步」检查状态。需要检查本机数据时点「暂停本机同步」。登录失效、连接冲突或环境缺少可靠的页面互斥时，设置会显示原因。有受支持的站点页面运行时，用户脚本可检查远端变化。关闭相关页面后，重新打开或恢复联网时会继续检查。

## 同步内容

| 内容 | 行为 |
| --- | --- |
| 作品标记和评分、演员、追新决策、关键词、标签 | 随业务数据同步 |
| 常用偏好、主题、快捷键和功能开关 | 按设置键同步 |
| 移动模式、列数和宽度 | 保留本机选择，可从该端快照恢复 |
| 活动及离线历史 | 随记录同步，其他设备记录供查看 |
| 登录、云盘授权、媒体库密钥、WebDAV 连接与信任 | 存放在当前安装 |

## 恢复与旧备份

- **同步历史**。展开「历史恢复」，点「查看恢复版本」，勾选要恢复的「影片、演员与记录」「个性化偏好」或「同时恢复本机布局」，再点「恢复所选版本」。恢复会建立恢复点，之后可按当前同步状态继续发布。
- **旧手动或循环备份**。旧文件仍在原目录，包括 `JHS-数据备份`。在「备份与数据」的 WebDAV 备份区点「查看备份」选择文件，也可先下载再用本地导入。7.0 的自动上传由多端同步负责。
- **版本保留**。同步快照位于 `JHS-同步`。新空库默认每个副本保留最近 5 份，以及过去 7 个 UTC 日期每天最后一份，重叠去重。旧库沿用已有设置，缺少策略时兼容原 10 份、30 天规则。同步在确认新文件写入并回读后清理自己的旧快照。

WebDAV 使用现有便携备份加密。使用可信服务，保留独立的本地导出，尤其在切换安装、变更连接或恢复大量数据前。可同步的设置与账号凭证采用各自的保存方式。技术规则见 [同步与恢复架构](architecture/adr/013-webdav-sync-recovery.md)。
