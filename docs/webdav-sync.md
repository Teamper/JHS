# WebDAV 多端自动同步与恢复（7.0 Dev）

安装 [develop 完整脚本](../JHS-7.0.dev.user.js)，确认名称为 `JHS Dev 7.0`，只启用一个 JHS 脚本。入口为 **设置 → 备份与数据 → 多端自动同步**。

## 接入与日常使用

1. 每个浏览器填写同一个 WebDAV 库的地址、用户名和密码，保存并授权地址即可自动接入，无需另外开启自动备份。同一用户脚本安装中的 JavDB、JavBus 和镜像站共享加密连接；电脑、手机和其他浏览器各配置一次。
2. 已有完整有效连接升级后自动验证。旧连接只写各站点候选；唯一连接自动采用，不同候选会暂停，请检查表单并点“使用此连接”选择一次。尚未打开站点的旧数据，要等访问该站点后才能迁移。显式保存或清空优先，清空不会回退旧密码。
3. 新端首次接入前创建本地恢复点，再合并云端数据。相同记录和偏好的冲突以云端为准，包括删除标记；本机独有内容保留并发布基线。之后自动按字段合并，不需要反复导入。

本地修改去抖 5 秒，连续修改最长 30 秒发布一次。前台每 30 秒检查，后台每 2 分钟尽力检查；打开页面、恢复可见和联网时立即检查。所有相关页面关闭后停止运行，重新打开自动追平，不需要常驻扩展。

同源标签页共用常规检查窗口，错峰打开多个页面不会按页面数量重复轮询；待发布的本地修改和“立即同步”仍可提前执行。普通业务保存仅核对触及的数据领域，完整核对继续在同步前修复遗漏变化；旧本地同步进度会自动移除重复副本模型，远端文件格式和恢复历史保持兼容。

未填完整连接时不发起自动网络请求。网络错误按 1、2、4、8、16、30 分钟退避；认证/授权失败暂停，修正连接后点“立即同步”。“暂停本机同步”影响此浏览器安装的各站点。设置显示待发布批次、成功时间、下一次检查/重试及清理失败状态。不支持可靠同源 Web Locks 的浏览器会显示原因并暂停。

## 数据、偏好与冲突

| 内容 | 行为 |
| --- | --- |
| 影片状态与资料、演员收藏/屏蔽、新作和决策、关键词、标签 | 自动同步；四个影片状态分别合并，集合按成员合并 |
| 主题、快捷键、功能开关、自定义来源、排序、新作视图、图片搜索站点、磁力来源、外部站点、标签展开、头像来源 | 自动同步；普通设置逐键合并，JSON 配置整体处理 |
| 移动模式、列数、宽度 | 保留本端选择，写入该端快照的布局恢复区 |
| 活动与离线历史 | UUID 去重，沿用裁剪限制；异端活动只供查看，离线历史不会触发提交或重试 |
| 密码、Cookie、Token、云盘授权、WebDAV 连接和信任、缓存、同步进度 | 留在本机，不进入同步快照 |

版本使用持久化逻辑计数与副本 ID，不依赖设备时间。不同字段保留双方修改，同一字段按确定的版本顺序自动决胜。删除标记不随历史文件过期，普通旧修改无法复活已删除记录；在收到删除后明确重新添加才会创建新一代。历史裁剪边界持续保留，旧快照不会反复填回已经裁剪的历史。

连接通过 CredentialService 整条加密保存在用户脚本 GM 存储。同步文件沿用现有便携备份加密，请仅使用可信 DAV 服务；文件加密不能替代服务权限和凭据保护。

## 版本保留与恢复

新同步库位于 `JHS-同步`。各内部副本独立写完整、不可变快照，文件名包含协议版本、副本 ID、序号、UTC 时间和密文哈希，不共同覆盖 `latest.json`。默认保留每副本最近 **10 份**，加过去 **30 个 UTC 日期每天最后一份**，重叠去重，通常不超过 40 份。高级设置可调整最近份数（至少 3）和每日保留天数（0–365）。旧自动备份已开启的份数按 `max(3, 原值)` 迁移。

只有上传成功、GET 回读校验通过且目录可列出后，才确认进度并清理自身旧文件。结果不明时重试已持久化的同一文件；上传期间新增修改留在下一批。清理失败独立提示，不因此重复上传。目录倒退、损坏文件或时间异常时保留数据等待重试，允许暂时超出保留数量。其他副本合法清理旧版本不影响同步，离线副本最新状态不会因年龄过期；文件消失不等于业务删除。未来协议版本会暂停应用和发布，需升级脚本。

在“历史恢复”点击“查看恢复版本”，选择快照，再勾选业务数据、个性化偏好或布局并确认恢复。恢复前沿用导入恢复点保护；恢复作为新修改同步到其他端，不回退副本身份、序号和同步进度。可先暂停本机同步检查结果，再恢复同步。旧手动备份和 `JHS-数据备份` 中的自动文件保持原样，原手动备份入口和格式继续可用。

业务保存成功后，同步元数据保存失败不会撤销业务数据。后续启动、恢复或同步前会核对实际数据与同步影子，补齐差异；远端落地日志未完成时先恢复，再接受新业务写入。清空所有站点数据和用户脚本存储仍可能丢失未上传内容，请在大规模操作前保留本地备份。

## 验证边界

按范围恢复在取得业务锁后读取本机最新数据，只更新勾选范围；其他标签页已保存的未选范围内容会保留。暂停自动同步时可继续查看和恢复版本，恢复不会解除暂停，也不会立即发布；点击恢复同步后才上传这些修改。同步快照除哈希验证外，还校验各类记录的主键、字段和数据类型，异常文件不会写入业务库。

单元测试覆盖字段收敛、删除/重建、上传期间修改、崩溃窗口、事务恢复、候选连接、清空隔离和保留规则。浏览器测试使用独立上下文、共享 GM 模拟和隔离 HTTP DAV 服务验证跨设备与跨站行为；这不等同于真实 WebDAV 账号、油猴安装或登录实站验收。完整门禁沿用现有脚本体积与启动性能预算，实际结果以本次交付报告为准。
