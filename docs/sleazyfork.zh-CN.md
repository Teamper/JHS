# JHS

JHS（JAV Helper Suite）是一款面向 JavDB、JavBus 的 Tampermonkey 用户脚本，用于整理作品状态、追踪演员新作、聚合资源与媒体信息，并提供统一离线、备份和统计工具。

> 当前稳定版本：**6.4.1**
>
> [GitHub 项目](https://github.com/Teamper/JHS) · [完整更新记录](https://github.com/Teamper/JHS/blob/main/CHANGELOG.md) · [问题反馈](https://github.com/Teamper/JHS/issues)

## 主要功能

### 作品状态与列表管理

- 收藏、已下载、已观看和主动屏蔽可以独立组合，不会互相覆盖。
- 提供“待鉴定”工作流，以及收藏未下载、收藏未观看、下载未观看、最近 7 天等智能筛选。
- 手动屏蔽、关键词和演员过滤统一收入口径明确的“屏蔽项”，不会混入普通列表。
- 支持自动翻页、批量标记、鉴定记录、状态撤销和跨标签页精准同步。
- 桌面使用 5+1 Quick Filter；移动端通过六项 FAB 菜单访问鉴定、筛选、排序和常用工具。

### 演员与新作品

- 收藏演员、维护演员黑名单，并在演员资料和作品卡片中显示状态。
- 定时检查收藏演员的新作品，并自动合并相同番号。即使同时打开多个页面，也不会重复检查；遇到失败会在稍后自动重试。
- 新作品页面支持按关键词、类别、VR、作品状态和处理方式组合筛选，也可以批量标记、忽略、暂缓、恢复或移出列表。
- 搜索、筛选、排序和翻页更加流畅，封面只在翻到对应页面时加载。批量操作失败的项目会继续保持选中，方便再次处理。
- 新作品、黑名单和设置面板会显示任务运行状态、上次完成时间与下次检查时间。

### 磁力、字幕与媒体

- 聚合多个磁力来源，自动排除重复结果，并显示字幕标识、综合评分和重点结果。
- 提供 SubtitleCat 字幕搜索、标题翻译、封面查看、截图和预览视频。
- 聚合评论、相关作品、热播、Top 250、FC2 信息、预告片与外部站点入口。

### 统一离线服务

- 支持 123 云盘 Magnet 离线任务。
- 支持 115 Magnet / ED2K 离线任务。
- 可选择默认服务，也可在提交时从当前已启用且支持该资源的服务中选择。
- 提供离线任务历史、失败原因和关联重试记录。
- 支持 115 文件增量匹配、播放入口和确认后重命名。

### 数据、备份与恢复

- 作品状态、演员列表、设置、活动日志和离线历史默认保存在当前浏览器中。
- 支持本地完整导入导出、WebDAV 备份与恢复、迁移快照和数据健康检查。
- 页面意外关闭后可以恢复未完成的数据写入；过新、无法安全识别的备份不会被强行导入。
- Stats 提供全库概览、当前页屏蔽项和自 6.4.0 起的 7/30 天活动趋势。

## 支持站点

| 站点 | 支持内容 |
| --- | --- |
| JavDB | 列表、详情、演员、搜索、状态管理、资源聚合及主要工具 |
| JavBus | 列表、详情、状态管理、图片/视频预览及资源工具 |
| 123 云盘 | 授权同步、Magnet 解析与离线任务提交 |
| 115 | Magnet / ED2K 离线、文件匹配、播放和确认重命名；默认关闭 |
| JavTrailers | 预告片辅助页面 |
| SubtitleCat | 字幕搜索辅助页面 |

## 快速开始

1. 安装 Tampermonkey 或兼容的用户脚本管理器。
2. [安装最新正式版 JHS](https://github.com/Teamper/JHS/releases/latest/download/JHS.user.js)。
3. 打开 JavDB 或 JavBus，使用页面中的 JHS 工具栏或移动端 FAB。
4. 在“待鉴定”中整理作品状态，在“新作品”中处理演员新作。
5. 如需云盘离线，在设置中启用并完成对应服务的授权或登录准备。
6. 升级、迁移设备或执行大量操作前，建议先导出备份。

## 作品状态说明

| 名称 | 说明 |
| --- | --- |
| 收藏 | 独立收藏标记，可与下载、已看或主动屏蔽组合 |
| 下载 | 表示作品已下载，不会自动改为已看 |
| 已看 | 表示作品已观看，不会覆盖收藏或下载 |
| 屏蔽项 | 当前页面中手动屏蔽、关键词和演员规则命中的合集；是检查这些内容的唯一入口 |
| 待鉴定 | 没有任何作品状态，并且未命中屏蔽规则的项目 |

普通和智能视图始终排除屏蔽项；“显示全部已鉴定内容”也不会覆盖这一规则。

## 当前版本

**6.4.1** 主要让后台检查、新作品列表和常用操作更稳定、更顺手：

- 同时打开多个页面时，新作品、黑名单和演员同步不会重复运行；检查失败后会在五分钟后自动再试。
- 新作品页面的搜索、组合筛选、排序和翻页更快，只会加载当前页面需要的封面。
- 批量处理时，成功项目会自动取消选择，失败项目会继续保留，方便重试；筛选后看不见的已选项目也会明确显示数量。
- 黑名单现在可以搜索名称、别名和演员 ID，并且可以同时使用多个筛选条件，一键重置也更加稳定。
- 新增清晰的任务状态、上次完成时间和下次检查时间；同时改善了按钮、移动端菜单、运行日志、离线提交和键盘操作。
- 导入或从外部网站取得的演员名称、头像和链接会经过更严格的检查，减少异常内容影响页面的风险。

此前 **6.4.0** 完善了作品状态、统一离线服务、数据升级与恢复能力。

完整版本记录请查看 [GitHub CHANGELOG](https://github.com/Teamper/JHS/blob/main/CHANGELOG.md)。

## 数据与隐私

- JHS 不提供云端账号系统，核心业务数据默认只保存在当前浏览器环境。
- WebDAV 仅在用户主动启用并配置后用于备份和恢复。
- 外部搜索、翻译、字幕、预告片和云盘功能会按需请求相应第三方服务。
- 清理浏览器站点数据、重置用户脚本存储或更换浏览器环境可能导致本地数据丢失。
- 请勿在公开 Issue 中提交 Cookie、Token、WebDAV 密码、云盘凭据或包含隐私的备份文件。

## 兼容性与已知限制

- 外部站点的页面结构、接口、访问限制或地区网络环境发生变化时，单项搜索、预览或离线功能可能暂时不可用。
- 123 云盘仅接收 Magnet；ED2K 只会路由至支持该类型且已启用的服务。
- 115 功能默认关闭，使用前需确认账号登录状态和相关设置。
- 活动趋势只统计 6.4.0 及之后由 JHS 记录的操作，不推算升级前历史。
- 本项目仅提供网页信息整理与效率增强能力。请遵守所在地法律、目标网站条款及第三方服务规则，并仅处理你有权访问的内容。
