# JHS 7.0.0-rc.1

7.0 的第一个候选版，欢迎愿意尝鲜的朋友帮忙试试。

这次主要整理了设置界面：设置改完统一点“保存设置”，手机上也更好找了。还修复了 115 把相邻番号文件算进结果的问题，并调整了状态反馈、列表操作和浮层交互。

安装前先备份数据、停用其他 JHS，再安装附件里的 `JHS-7.0.rc.user.js`。RC 会自动跟随后续 7.0 RC 更新，正式版发布后需要手动切换。网站数据沿用现有存储；云盘或 WebDAV 的凭证可能需要重新授权。

遇到问题可以到 [Issues](https://github.com/Teamper/JHS/issues) 留一下站点、版本、操作步骤和截图，方便我们复现。
