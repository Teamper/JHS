# JHS 7.0.0-rc.3

相对 **7.0.0-rc.2**，本版本修复 JavDB 翻页、详情重复译文和 FC2 交互。收藏演员资料支持断点续跑，备份恢复可以安全停止旧的资料补齐批次。

## 新增

- 收藏演员资料按批补齐，并可在新作品中按身高、罩杯和年龄筛选。
- JavDB 的 FC2 页面与弹窗支持使用当前网页登录账号标记「看过」和撤销。「想看」沿用当前账号。

## 修复

- JavDB 主列表与推荐区并存时仍可识别外层分页。标签结果叠加 JHS 状态筛选时，预加载范围内会继续检查后续页。
- 普通详情的原题从隐藏切到可见时只显示一条自动译文。关闭预览后清理播放器控件和挂起请求。
- FC2 剧照恢复触摸切图和放大后拖动，站内磁力需要登录时可登录并重试。
- 演员资料核验兼容更多维基别名、常见异体字和全角数据。旧补齐批次在导入、恢复或清理后失效，关页或限流后可续跑。
- WebDAV 备份列表兼容目录编码和仅提供大小的 JSON 文件。鉴定记录的顶部筛选和页尾操作在窄屏仍可触达。

## 改进

- 作品标记和追新决策独立保存。演员重绑后保留原队列中的作品。
- 整理功能的启动和清理、共享状态事务和跨端构建，保留既有备份格式与各渠道的安装方式。

## 升级说明

- 已安装 RC2 的用户从原 RC 通道更新。切换渠道或从 6.5.2 升级前，请在「备份与数据」导出备份。
- 7.0 使用数据版本 4。返回 6.5.2 时使用升级前的备份。RC 系列与后续 7.0 正式版使用独立的更新通道，切换正式版时按发布说明手动安装。
