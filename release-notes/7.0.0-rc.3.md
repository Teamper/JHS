# JHS 7.0.0-rc.3

相对 **7.0.0-rc.2**，本版加入收藏演员资料补齐与追新的身材筛选，补齐 JavDB FC2 原站「看过」操作，并修复筛选后瀑布流停住、详情译文重复和 WebDAV 历史备份漏列。

## 新增

### 收藏演员资料补齐与新作品筛选

- 后台为收藏演员分批补齐经身份核验的资料。演员页与详情可复用已保存的资料，关闭页面或遇到限流后，自动检测可从已保存的进度继续。见 [#16](https://github.com/Teamper/JHS/pull/16) 和 [#20](https://github.com/Teamper/JHS/pull/20)。
- 「新作品」的演员和作品视图均可按身高、年龄、罩杯筛选，支持重置筛选条件。

### JavDB FC2 原站「看过」

- 从 JavDB 的 FC2 列表打开弹窗或独立详情后，可以使用当前网页登录账号标记「看过」或撤销。已有「想看」也沿用该账号。关联反馈 [#18](https://github.com/Teamper/JHS/issues/18)。

## 修复

### JavDB 翻页与详情

- JavDB 主列表和每周推荐并存时，正确识别属于主列表的外层分页。原站标签叠加 JHS 状态筛选后，若当前页没有匹配项且页尾仍在预加载范围内，瀑布流会继续检查后续页。关联反馈 [#19](https://github.com/Teamper/JHS/issues/19)。
- 普通详情从隐藏原题切回显示时只保留一条自动译文。关闭列表中的详情预览后移除播放器工具栏，取消挂起的加载，避免旧结果影响重新打开的预览。
- FC2 剧照支持触屏左右切图，到首尾停止，放大后可拖动查看。站内磁力需要登录时可登录后重试，加载或失败时仍可打开对应的原站详情。相关反馈 [#17](https://github.com/Teamper/JHS/issues/17)。

### 备份恢复与演员资料

- WebDAV「查看备份」兼容不同目录编码和仅返回文件大小的 JSON 备份，可下载并恢复这些文件。删除前仍核对服务端返回的文件类型，遇到无法识别的列表会提示加载失败。关联反馈 [#18](https://github.com/Teamper/JHS/issues/18)。
- 升级、导入或恢复后会在后续检测中补齐缺少的演员资料。恢复或清理使旧批次失效，避免迟到结果覆盖恢复后的库。维基百科核验兼容分行别名、姓名空格、括号附注、常见异体字和全角资料。见 [#20](https://github.com/Teamper/JHS/pull/20)。
- 窄屏的鉴定记录保留顶部筛选、可操作的表格区域和页尾分页。嵌套确认框按当前弹窗顺序显示，关闭后焦点回到相应操作。见 [#16](https://github.com/Teamper/JHS/pull/16)。

## 改进

- 作品标记和追新决策独立保存。重绑演员来源后保留从原来源迁入的待处理作品，后续扫描继续沿用这些记录。
- 公共缓存清理会复核刚写入的条目。翻译与媒体库的连接设置保留跨站并发修订，用户可在发生冲突时选择保留哪一份。
- 收拢功能启动、状态提交和异步清理，保留旧设置键及备份格式。页面诊断可在控制台用 `window.jhsDiagnostics` 采样。

## 升级说明

- 已安装 RC2 时，从原 RC 通道更新 **JHS RC 7.0**，沿用当前安装的数据和凭证。首次安装请使用本页的 **JHS-7.0.rc.user.js**，同一站点只启用一份 JHS 脚本。
- 从 6.5.2 升级或切换安装渠道前，在「备份与数据」导出备份。7.0 使用数据版本 4，返回 6.5.2 时使用升级前的备份。
- RC 与后续 7.0 正式版各有独立更新通道。正式版发布后，按当期说明手动切换并按需重新连接账号或服务。
