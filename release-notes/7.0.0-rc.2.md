# JHS 7.0.0-rc.2

相对 **7.0.0-rc.1**，本版本新增多服务标题翻译、1—5 星个人评分、跨页选择与 JavDB 清单管理、字幕聚合与 115 上传、Emby / Jellyfin 媒体库联动、隐私遮罩以及扩展长缩略图来源，改由独立开关协调全部功能生命周期，完善“新作品检测”来源不可用诊断与演员重绑并将“高亮收藏演员”接入海报墙，同时修复多项首页多列表、设置保存、媒体解析与运行时稳定性问题。

## 新增

### 多服务标题翻译与跨页翻译

- 翻译配置支持具名 DeepSeek、OpenAI Responses、Gemini、三类自定义协议、DeepLX 与 DeepL Free/Pro，继续保留 Google 作为默认翻译服务及既有缓存；连接地址与令牌加密保存在本机，备用链需由用户显式选择，结果接口返回来源、缓存命中与服务用量。
- 普通详情与 FC2 工作区共用标题翻译面板，列表页支持跨页勾选批量翻译。
- 自动翻译按可见标题并发调度（默认每页并发 2，可在设置中调整），在遮罩开启、弹窗关闭或切换服务时自动取消旧消费者，并区分鉴权、限流、额度、拒绝、空结果和截断异常。

### 独立个人评分

- 新增 1—5 星个人评分，覆盖详情评分控件、列表卡片评分徽标、历史记录按评分筛选排序及批量评分。
- 评分纳入导出备份、恢复与 WebDAV 字段同步；存储结构升级至数据版本 4，升级前保留恢复点。

### 跨页选择与 JavDB 清单管理

- 新增跨页影片选择入口，可查看 JavDB 现有清单目录与成员，支持批量加入及移出清单预览。
- 清单任务逐项保存进度，执行前核对网页登录账号、跨标签页互斥与网站最终状态，支持停止后结算及刷新恢复；停用对应功能后及时取消任务并清理入口。

### 字幕聚合与 115 字幕上传

- 普通详情与 FC2 工作区共用字幕面板，聚合迅雷与 SubtitleCat 来源，提供来源和语言筛选、原始字节预览与下载。
- 115 网盘字幕上传支持多目录选择与预览、同名跳过及待核实记录恢复。

### Emby / Jellyfin 媒体库联动

- 支持在本机加密保存多个 Emby / Jellyfin 连接，配置代理子路径与可选用户范围（外部服务默认关闭）；输入地址省略协议时自动补全 HTTP，兼容局域网 IP、主机名与端口。
- 连接测试与保存对缺失字段及格式错误给出明确提示，区分认证、权限、超时、网络和服务器响应异常；列表与详情提供目录身份核对、可见卡片入库查询、入库筛选、版本入口及手动刷新。

### 隐私遮罩与长缩略图扩展来源

- 在桌面“更多”菜单与移动菜单加入隐私遮罩，支持可配置快捷键、按住临时查看及遮罩偏好；开启遮罩后暂停封面悬浮预览，松开或窗口失焦后恢复隐藏。
- 新增默认关闭的 ProjectJav、JavFree 长缩略图来源，支持按启用顺序自动回退、分源重试、完整番号校验和来源状态诊断。

## 修复

### 新作品检测与收藏演员高亮

- 完善“新作品检测”来源不可用处理：在异常面板明确说明页面不存在（404）多因站方合并或下架演员主页所致，保留已有新作品并新增**查看主页**、**重新绑定**（按演员名或别名检索新页，或直接粘贴新演员页链接与 `starId`，原子迁移并合并原作品与备注）、**重试**与**移除**四项操作；演员卡片展示`来源不可用`徽标，编辑框支持只读查看与重绑 `starId`，站方取消收藏返回 404 时兼容清理本地记录。
- 修正“高亮收藏演员”列表生效范围与配置入口：在 JavDB 列表、JavBus 列表及每周推荐补充区中，基于本地收藏演员的新作品、作品演员索引与卡片内演员信息零额外请求匹配并高亮作品卡片与`收藏演员`徽标（硬屏蔽作品不叠加，不改变筛选标签与统计计数）；收藏变更即时刷新列表，详情页继续保留演员边框高亮（修复独立注册高亮样式及设置保存联动问题），并在 JavDB 与 JavBus 两站的“列表与详情”设置中均提供“高亮收藏演员”独立开关。

### 首页多列表与推荐区

- 修复 JavDB 首页多列表边界与跨区排序问题：将工具栏、排序、筛选、计数、封面处理、批量操作与翻页严格限定在正式列表，边界不明确时停止增强；拒绝失效根节点的迟到加载响应，排序保留卡片及非卡片节点。
- 补回 JavDB 每周推荐区的高清封面、悬浮大图、卡片工具、状态标签、导航和标题翻译；推荐区保持原生顺序与收起交互，并与正式列表同步同片状态。

### 磁力聚合、115 与站点解析

- 115 列表与详情改用账号隔离的分页匹配与统一完整番号复核，兼容紧凑补零文件名与独立数字后缀，到达分页上限后可继续加载，批量重命名保留分片后缀并复核账号。
- JavStore 按标题、文章路径及结构化封面 CID 核验番号，过滤发布日期与英文标题误拼成的伪番号、文章画质前缀及 DMM 补零封面编号造成的漏图与错图；未知封面通过详情复核，失败给出具体原因及重试，修复 MSFH-021、TENN-052、SONE-917 等场景。
- 修复 FC2 详情加载、登录提示和重试期间丢失卡片已有标题/封面/发行日期的问题，详情改用完整 `FC2-PPV` 格式检索长缩略图（修复 FC2-4995326 等场景），复用脚本 JavDB 登录凭证并提供登录与自动重载入口，同时修正 FC2 深色主题标题、演员标签对比度及缺失时长显示。

### 设置、撤销与运行时稳定性

- 修复完整设置切换功能开关丢失键盘焦点、短表单空白高度及关闭后快捷面板被清空的问题；桌面快捷设置鼠标仍处于交互区时不再提前启动 200ms 关闭计时，JavBus 快捷面板位置限制在视口内。
- 修复状态撤销覆盖后续独立下载/备注修改的问题：仅恢复本次操作拥有的字段，并按撤销后的有效状态恢复新作品。
- 修复 HTTP 4xx 状态误计入熔断器、`half-open` 探测死锁、原生 `fetch` 解析非 JSON 错误页崩溃、`undoTransaction` 原子提交、多视图与控制器关闭/停用后生命周期残留，以及嵌套弹窗叠放、`OwnedPopover` Escape 隔离、`trapFocus` 对 `[inert]` 节点的排除、悬浮预览/Tooltip 残留与移动端 FAB 避让批量操作栏等问题。

## 改进

### 独立功能控制与设置交互精简

- 移除增强总开关与翻译请求预算限制，全部功能通过独立开关协调 `FeatureRuntime`、命令及界面生命周期，停用即撤下入口并停止对应消费者，同源标签保持同步。
- 翻译、媒体库与隐私配置并入完整设置草稿统一页底保存，保存失败自动展开父级折叠组，连接读写通过加密修订检查并发并在冲突时保留草稿；翻译默认仅展示译文，统一下拉框、工具栏与详情分区结构。

### 磁力聚合、界面规范与运行性能

- 磁力聚合按来源渐进显示结果与状态，支持质量、做种、日期和大小排序及字幕、4K、无码/破解筛选，统一 Base32/十六进制哈希去重并补齐来源信息，刷新时保留操作焦点。
- 统一设计令牌至 `--jhs-*` 变量，统一弹窗与危险确认操作采用“取消在左、确认在右”布局与语义高亮，对齐窄屏命令栏、外部站点/FC2 目录、列表菜单/桌面/详情/移动端操作顺序与可访问状态。
- 状态、活动记录与同步证明改用持锁原生事务，同步大库计算使用惰性内嵌 Worker 并提供协作回退；增强 IndexedDB 连接复用、CAS 签名预计算、事务超时保护、LRU 有界缓存、加密修订裁剪、推荐区复用正式列表快照及快捷筛选同帧合并，显著降低列表及后台操作卡顿。

## 升级说明

- 与 **7.0.0-rc.1** 共用 **JHS RC 7.0** 脚本身份与固定更新通道，安装 **JHS-7.0.rc.user.js** 即可直接升级并保留已有数据；停用正式版或 Dev，仅启用一个脚本。
- 首次从旧数据升级会迁至数据版本 4 并保留升级前恢复点；新增的第三方翻译、Emby / Jellyfin 媒体库与外部长缩略图来源默认关闭或仅本机加密保存凭证，按需在设置中启用。
