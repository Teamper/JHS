# JHS 7.0.0-rc.2

相对 **7.0.0-rc.1**，本版本完善“新作品检测”异常来源的诊断与演员重绑流程，将“高亮收藏演员”扩展为海报墙作品卡片高亮，并修复多项界面一致性、首页多列表、设置交互及核心稳定性问题。

## 修复

### 新作品检测与收藏演员高亮

- 完善“新作品检测”来源不可用处理：明确说明页面不存在（404）多因站方合并或下架演员页所致；保留已有作品并增加“查看主页”“重新绑定（支持按名称/别名检索新页，或直接粘贴新演员页链接与 `starId`，自动迁移并合并新作品与备注）”“重试”“移除”操作；演员卡片补充“来源不可用”徽标，编辑框支持查看与重绑 `starId`。
- 修正“高亮收藏演员”列表体验：在 JavDB、JavBus 列表及每周推荐补充区中，基于本地收藏演员作品缓存、作品演员索引与卡片内演员链接/名称零额外请求匹配并高亮作品卡片与“收藏演员”徽标（硬屏蔽卡片不叠加，不改变筛选标签及统计计数）；保留详情页演员高亮，收藏变更即时刷新列表，在 JavDB 与 JavBus“列表与详情”设置中均提供独立开关。

### 列表、设置与解析修复

- 修复 JavDB 首页多列表边界与跨区排序，补回每周推荐卡片增强并保持列表操作隔离；修复收藏演员详情高亮样式缺失。
- 修复完整设置的功能开关在键盘切换时丢失焦点，以及桌面快捷设置在鼠标仍位于交互区时提前关闭的问题。
- 修复 JavStore 封面编号补零、日期伪番号及文章匹配误判（含 SONE-917、MSFH-021、TENN-052 等场景），解析失败提供具体原因及重试。
- 修复 HTTP 4xx 状态误计入熔断器、`half-open` 探测死锁、原生 fetch 解析非 JSON 错误页崩溃、`undoTransaction` 原子提交及多控制器生命周期残留。

## 改进

- 统一设计令牌与交互规范：收口设置样式至 `--jhs-*` 变量，修复窄屏命令栏隐藏与溢出，统一确认弹窗“取消在左、确认在右”与危险操作语义，对齐四态操作顺序并补全可访问状态。
- 增强凭证派生与修订裁剪、LRU 有界缓存、媒体库淘汰、IndexedDB 连接复用及长列表评估与翻页性能，减少浏览器测试夹具传输开销。

## 升级说明

- 与 **7.0.0-rc.1** 共用 **JHS RC 7.0** 脚本身份与更新通道，安装 **JHS-7.0.rc.user.js** 即可直接升级并保留已有数据；停用正式版或 Dev，仅启用一个脚本。
