# Android 离线预览产品基线

## 首轮任务

| 入口 | 操作 | 可验证的结果与返回 |
| --- | --- | --- |
| 发现 | 输入番号、标题或演员，选择分类／榜单，应用筛选和排序，进详情点收藏 | 同一作品出现在片库。返回保留查询、筛选、排序、视图和作品位置。取消筛选恢复原条件。样本失败时保留已有结果，原位重试。 |
| 追新 | 看待办，按演员筛选，连续处理两部，暂缓一部，再撤销 | 多演员来源显示在同一作品。处理后继续队列，暂缓在对应视图可手动恢复。收藏不移出待办。 |
| 片库 | 组合状态、清单、关键词筛选，编辑备注，选两部批量标记 | 数量实时更新，一次撤销整批。内置清单可增减作品，屏蔽作品仍可编辑。 |

## 页面树

- 发现 → 搜索／分类／榜单 → 作品详情 → 演员作品或相关作品
- 追新 → 待办／暂缓／已处理／忽略 → 作品详情 → 继续队列
- 片库 → 检索与组合筛选／多选 → 作品详情 → 备注与清单
- 我的 → 汇总入口／本地模拟任务／显示与隐私／演示场景。备份归数据管理，复杂统计归统计，高级工具归诊断。

## 状态表

| 状态 | 范围 | 行为 |
| --- | --- | --- |
| 收藏、已下载、已看、屏蔽 | 单作品 | 四个独立布尔值。屏蔽从发现和演员页派生过滤。 |
| 评分、备注、清单 | 单作品 | 各自独立修改。清单增减和批量标记可撤销。 |
| 待办、已处理、暂缓、忽略 | 单作品的追新条目 | 同一作品归并演员来源。待办可进入其余三态，其他状态可恢复待办。 |
| 等待、进行中、完成、失败、取消 | 单任务 | 失败可重试，等待和进行中可取消，完成和取消可查看。 |
| 原有结果、加载、空、失败 | 当前列表 | 首次失败保留原有结果；重试成功追加其余样本。 |
| 主题、遮罩 | 设备 | 重启保留，临时查看在离开页面或超时时收回。 |
| 栈、查询、筛选、排序、视图、多选、锚点 | 各 Tab／路由 | 当前会话保留。系统返回先让键盘收起，再关闭媒体或弹层、退出多选、回上一级。 |

## 灰阶线框与可点击流程

在预览 URL 附加 `?mode=wireframe` 打开灰阶原型，可从四个底部入口走完整任务。普通地址呈现高保真界面。

```text
发现                追新                    片库
[搜索____________]  追新待办  N             [检索____________]
[范围][筛选][排序]  [待办][暂缓] [演员]      [筛选][排序][选择]
[图]       [图]    [图] 标题 / 演员         [图] 标题 / 个人状态
标题       标题     [处理][暂缓][忽略]           评分 / 备注
      [发现 | 追新 | 片库 | 我的]

详情      [返回]                    [隐私]
          [封面]
          完整标题 / 番号
          [收藏][下载][已看][屏蔽]  [评分]
          发行资料 / 演员 / 备注与清单
          [预告] [长图] [截图] → 全屏
          [资源] [评价] [相关作品]
```

| 路径 | 点击顺序 |
| --- | --- |
| 正常 | 发现 → 搜索 → 详情 → 收藏 → 返回；追新 → 处理 → 暂缓 → 撤销；片库 → 筛选 → 详情备注 → 返回 → 多选 → 已看 |
| 取消 | 发现／片库 → 筛选 → 更改草稿 → 取消或 Android 返回 |
| 失败 | 我的 → 演示场景 → 一次失败 → 发现 → 重试 |
| 媒体 | 详情 → 长图或截图 → 缩放／前后翻 → 关闭，回到原图所在位置 |

## 视觉与组件

浅色使用暖白页面、深墨文字和深青强调色，深色使用墨绿黑页面、浅色文本和薄荷强调色。使用系统字体，页面标题 26px、作品标题 15–22px、元数据 13–14px。间距基于 4px，内容边距 16px。海报按原比例，标题自然换行。表面提升用于导航、弹层和反馈。导航玻璃沿用共享镜片组件，交互控件至少 48×48 CSS px，在 Android 的 device-width 布局下对应 dp。焦点有独立轮廓，重试、缩放、翻页和选择均可点按。支持系统减少动效和大字号，普通文字对比度目标为 4.5:1。

## 回归任务

更新交互后可用内置样片重复以下操作，核对状态、返回位置和撤销结果。

1. 找到「沿河的午后」，加为收藏，再回到刚才的搜索结果。
2. 处理任意两部追新，暂缓第三部，再撤回暂缓决定。
3. 在片库找到两部已收藏的作品，写一条备注，然后一起标为已看。
